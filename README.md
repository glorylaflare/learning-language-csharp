# Aprendendo C# e .NET

Este repositório documenta minha jornada de aprendizado em C# e .NET, desde os conceitos fundamentais até tópicos avançados. O objetivo é demonstrar minha evolução ao longo do tempo através de projetos pequenos, mas que incorporam diversos conceitos e técnicas importantes da linguagem e do framework.

## Estrutura do Repositório

O repositório está organizado por anos, refletindo o progresso cronológico do aprendizado.

### learning-2025
Projetos desenvolvidos em 2025, focando em conceitos básicos e intermediários.

- **AgenciaViagem1**: Aplicação web MVC para uma agência de viagens, utilizando Entity Framework para persistência de dados e estrutura típica de ASP.NET Core.
- **AgendaContatos**: Aplicação console para gerenciar contatos, com armazenamento em JSON, demonstrando manipulação de arquivos e estruturas de dados.
- **BancoBrasil**: Projeto básico de um sistema bancário, explorando conceitos de orientação a objetos e lógica de negócio.
- **BancoWebRazor**: Aplicação web com Razor Pages para operações bancárias, incluindo transações e usuários, utilizando ASP.NET Core.
- **LearnEntity**: Projeto focado em aprender Entity Framework, com configurações de banco de dados e operações CRUD.
- **TelaDeLogin**: Implementação de uma tela de login simples, explorando autenticação básica.
- **TesteAgencia**: Projeto de teste para uma agência, possivelmente para praticar testes unitários e integração.

### learning-2026
Projetos mais recentes, incorporando conceitos avançados e melhores práticas.

## Como Usar
Cada projeto é independente e pode ser executado individualmente. Certifique-se de ter o .NET SDK instalado. Navegue até a pasta do projeto e execute `dotnet run`.
